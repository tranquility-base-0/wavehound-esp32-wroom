1. CT CONCEPT AND ARCHITECTURE (design contract)
------------------------------------------------
CT is a counter-surveillance mode: detect devices that persist across
CHANGING RF environments. Environments are RF-identity neighborhoods,
not places. Two questions: (1) did the environment change (segmentation),
(2) what persisted across the change (persistence payload).

Dual-core ownership model:
  Core 0 (RX context, sniffer_callback):
    - ct_observe_bssid() inserts identities into acc
    - marks per-window touch masks, byte counter, probe hit mask
    - counts rejected inserts
  Core 1 (main loop, processCtData()):
    - fixed 5 s window clock; window close under pause fence (F10)
    - validity = window closed while pause_sniffing == false
    - three evidence channels (per window), 2-of-3 quorum -> commit
    - acc -> hist ring (committed metrics), persistence pass
    - [CT-*] serial diagnostics

F10 fence discipline: structural Core-1 work runs with
pause_sniffing = true; delay(10); ... pause_sniffing = was_paused;
(validity is read BEFORE raising the fence; the fence restore does not
clear a menu-held pause).

Representation contract (must be preserved):
  - BSSIDs: exact 6-byte identities, never hashed.
  - SSIDs: CT-local copies (never references into ssidPool/bssidCache).
  - Counts are DERIVED mirrors, never independent truth.
  - Truncation flags are sticky and set ONLY on a failed insertion of a
    genuinely new identity (reaching capacity is NOT proof of overflow).
  - No BSSID<->SSID association pairs stored; ratio descriptive only.
  - Live accumulator arrays (acc) remain authoritative for evidence;
    no persistent references into transient probe/SSID/BSSID storage.
  - Single accumulator acc: window set and transition-candidate set
    share one environment record (candidate_active/phase fields exist
    in CTState for the sequenced design; commit copies acc into the
    next hist slot).

  uint8_t  bssid[48][6];

  uint32_t last_seen;                  //   empty-accumulator sentinel

  uint16_t window_count;               // VALID windows folded in
  uint8_t  n_bssid;                    // derived count mirror
  uint8_t  n_ssid;
  uint8_t  flags;                      // sticky truncation bits
  uint8_t  reserved;
};

[UNCOMMITTED] struct CtEnvRecord {     // 32 B, immutable committed metrics
  uint32_t first_seen;                 // millis of segment's first valid window
  uint32_t last_seen;                  // millis of its last valid window
  uint32_t byte_mean_q8kib;            // horizon EWMA per-window bytes, KiB Q8.8
  uint32_t byte_std_q8kib;             // isqrt of byte-variance EWMA, KiB Q8.8
  uint16_t mu_b_q8;                    // final horizon EWMA mean of B
  uint16_t sig_b_q8;                   // isqrt of final horizon EWMA var of B
  uint16_t mu_s_q8;
  uint16_t sig_s_q8;
  uint16_t env_id;                     // = env_seq at commit
  uint16_t window_count;               // valid windows folded in
  uint8_t  flags;                      // CLASS_T + inherited acc trunc bits
  uint8_t  reserved;

5. SEGMENTATION EVIDENCE (horizon-bounded baselines)
----------------------------------------------------
All fixed-point integer, no floats. Q8.8 = value*256 for counts/means/
evidence; Q8.16 = value^2*65536 for variance (sigma = isqrt(var) directly,
no shift). Evidence Q8.8 clamped to 8192 (=32.0) where input unbounded
(turnover via rej). Bounds: |resid| <= 48*256 = 12288; resid^2 <= 1.51e8
fits int32; var fits uint32; byte path uses u64 (KiB^2 Q8.16).

Constants (ct.cpp, all trace-tunables, none sacred):
  CT_C1_Q8        512   // population threshold floor C1 = 2 counts
  CT_C2S_NUM/DEN  5/4   // threshold slope 1.25*sigma
  CT_SIGMA_T_Q8   384   // provisional-T boundary (sigma >= 1.5 counts)
  CT_BASE_SHIFT   5     // baseline EWMA alpha = 1/32 (horizon ~160 s)
  CT_VAR_FLOOR_Q8 256   // variance-gate floor (1.0 count)
  CT_K3           3     // churn normalization K
  CT_K5           3     // turnover normalization K
  CT_TURN_N_MAX_Q8 8192 // turnover evidence clamp (32.0)
  CT_N_MIN        3     // persistence length (windows)
  evidence EWMA alpha = 1/8 (frozen since Step 5)

Three LIVE channels (2-of-3 quorum): POPULATION, CHURN, TURNOVER.
The former RETENTION channel is RETIRED (not in quorum; machinery and
the hist-identity arrays it consumed deleted).

Per-window order (evidence ALWAYS against the PRE-update baseline):

  1. POPULATION [B,S]:
     n_pre==0: EXACT seed mu = cur*256, var = 0, no evidence;
       [CT-SEED] win=%u mu=%u/%u.
     n_pre>=1: sigma = isqrt(var) per dimension.
       n_pre>=2: D = max(|dB_q8|,|dS_q8|); thr_q8 = C1 + (sigma_max*5)/4
         (>= 512); n_pop = (D<<8)/thr (<= 6144, fits u16);
         evidence_update(pop); provisional E/T: ct_prov_is_t =
         (sigma_max >= CT_SIGMA_T_Q8) (description only, never resets).
     Absorb AFTER evidence:
       mu += (cur*256 - mu) >> 5            (int32 arithmetic)
       variance, EXCURSION-GATED (Huber-style): update only when
         n_pre < 4 (warm-up) OR |resid| <= 3*sigma + CT_VAR_FLOOR_Q8;
         var += (resid^2 >> 5) - (var >> 5).
       Design intent: steps are learned by mu, never laundered into sigma;
       without the gate a step's own residual inflates the threshold within
       one window and self-shields the transition.

  2. CHURN [|dB|,|dS|]:
     n_pre==1 (first delta): seed m_ab with the first |delta|*256.
     n_pre>=2: ex = max(0, |delta|*256 - m_ab) (both dims, take max);
       scale = K3 * max(m_ab, 256); n = (ex<<8)/scale; evidence_update.
     Absorb after evidence: m_ab += (|delta|*256 - m_ab) >> 5.
     (Excess churn: sustained walking self-quietens as m adapts.)

  3. TURNOVER (identity dynamics, adjacent-window):
     turnover = popcount(smask & ~prev_smask)   // new SSIDs
              + popcount(prev_smask & ~smask)   // vanished SSIDs
              + rej                             // untracked-stream arrivals
     No ABSTAIN case: needs only a previous valid window (empty->populated
     IS turnover). Bit->SSID mapping stable for acc's lifetime, so mask
     algebra IS identity algebra; no strings compared/stored. Post-commit
     re-learn of the same environment produces ~no turnover (prev mask
     tracks it) — no artificial post-commit spike. rej is FLUX-WEIGHTED
     (frames x unseen identities; rejected identities are not recorded so
     each later frame re-attempts; rej <= 2*obs).
     n_pre==1: seed m_turn = turnover*256 (u32; can exceed 255 via rej).
     n_pre>=2: ex = max(0, turnover*256 - m_turn); scale = K5*max(m_turn,256);
       clamp PRE-shift: if ex > (CT_TURN_N_MAX_Q8>>8)*scale -> n = 8192
       else n = (ex<<8)/scale; evidence_update.
     Absorb after evidence: m_turn += (turnover*256 - m_turn) >> 5.
     ct_prev_smask = smask (after consumption).

  Common evidence mechanism — ct_evidence_update(ewma, persist, n_q8):
    ewma = (ewma*7 + n) >> 3;            // alpha = 1/8
    if (ewma > 256) { persist++ (cap 255); return persist == CT_N_MIN; }
    persist = 0; return false;
    Returns true exactly on the N_MIN-1 -> N_MIN crossing (feeds the
    [CT-TRIG] diagnostic only; may re-fire after a drop+re-rise). The
    persistence state IS the trigger state (no latch).

  Quorum: trig = (persist_pop>=3) + (persist_churn>=3) + (persist_turn>=3);
  if (trig >= 2) ct_commit_segment() — INSIDE the fence, BEFORE the
  post-fence diagnostics.

  Cold start (uniform): window 1 no evidence (seed); window 2 seeds
  churn/turnover baselines; window 3+ all three channels vote.

  Per-segment reset — ct_reset_segment_stats(): zeroes mu_b/s, var_b/s,
  byte mean/var, min/max envelopes, ct_have_obs, m_ab_b/s, prev_smask,
  m_turn, evidence EWMAs (pop/churn/turn), persistences, ct_prov_is_t,
  derivative scratch (prev_b/s, prev_d_b/s, have flags). Called at CT
  exit/re-entry and at every commit. Trigger state must never survive an
  acc reset (bit indices are meaningless across it).

6. COMMIT AND PERSISTENCE (ct.cpp)
-----------------------------------
ct_commit_segment() (fence held):
  next = (current_idx + 1) % MAX_CT_ENVIRONMENTS;
  hist[next] = immutable metrics snapshot:
    first_seen/last_seen = acc stamps (duration = last - first);
    byte_mean_q8kib, byte_std = isqrt64(byte_var); mu_b/mu_s;
    sig_b/sig_s = isqrt32(var_b/var_s); env_id = env_seq;
    window_count = acc.window_count;
    flags = (acc.flags & (BSSID_TRUNC|SSID_TRUNC)) | (prov_is_t ? CLASS_T:0).
  current_idx = next;
  ct_persist_commit(dst.env_id, dst.window_count);   // fence still held
  env_seq++;
  memset(&acc, 0, sizeof(CtEnvironment));
  ct_reset_segment_stats();
  Ring-full overwrites oldest; env_seq keeps global order.

Persistence pass (Core 1, commit time, fence held; all inputs read ONCE
and immediately copied into CT-owned state — no persistent reference to a
probeList slot, ssidPool node, or bssidCache entry):

  ct_persist_commit(env, win):
    - AP evidence: every BSSID in the committed acc set ->
      ct_persist_observe(mac, is_ap=true, probe_slot=-1,
                         acc.first_seen, acc.last_seen, env, win).
      (Per-BSSID stamps do not exist in acc; env-level stamps are the
      documented closest available observation times.)
    - Probe evidence: hits = ct_probe_hit_mask; ct_probe_hit_mask = 0;
      iterate by __builtin_ctzll, hits &= hits-1; skip s >= MAX_PROBE_SLOTS;
      ct_persist_observe(probeList[s].mac, false, s,
                         probeList[s].first_seen, probeList[s].last_seen,
                         env, win) — identity re-read under the fence and
      immediately copied.

  ct_persist_mac_sane(): reject multicast/group (bit0 of byte 0), all-zero,
  broadcast.

  ct_persist_observe(mac, is_ap, probe_slot, src_first, src_last, env, win):
    a) Already persistent (ct_persist_find): ct_persist_env_insert(env);
       first_seen = min(first_seen, src_first); last_seen = max(...);
       flags |= type; SSID refresh (probe: walk chain; AP:
       ct_persist_ap_enrich — bssidCache copy becomes first-known SSID
       ONLY while record has none); vendor copy; country copy (AP only).
    b) Pending (ct_pend_find):
       - same env: merge type flag, first_seen min. (AP/probe identity
         merging within one environment.)
       - second DISTINCT env: PROMOTE. If persist.count >= 20: evict the
         least-recently-seen row (LRU by last_seen; ties -> lowest index),
         log "[CT-PERSIST] win=%u evict-row idx=%u", swap-with-last,
         count--. New row: memset; mac/oui copy; first_seen = min(src_first,
         pend.first_seen); last_seen = src_last; env_seen[0] =
         pend.first_env_id, env_seen[1] = env, env_count = 2;
         flags = pend.flags | fl; SSID chain walk + vendor copy (probe) or
         AP enrich + country copy (AP). Capture promo_first_env BEFORE
         ct_pend_remove (see §9); remove pending entry (swap-with-last);
         log "[CT-PERSIST] win=%u promo mac=%02X... envs=E%u,E%u".
    c) First evidence ever: enter pending pool. Pool full (>= 192): evict
       the entry with the SMALLEST first_env_id (ties -> lowest index) —
       oldest-environment eviction, deterministic, false-negative-only;
       swap-with-last. Append with first_seen/first_env_id/mac/flags.

  ct_persist_env_insert(d, env): dedup against stored first 8; store while
  < 8; once full set CT_PFLAG_ENV_OVF and only bump env_count (saturating
  u8). Documented limitation: once the list is full, revisits of unstored
  env ids increment the count again.

9. IMPLEMENTATION HISTORY / CORRECTIONS (fixes that must be preserved)
----------------------------------------------------------------------
1. UNSIGNED BYTE-VARIANCE SUBTRACTION CORRECTION [UNCOMMITTED ct.cpp]:
   The byte-variance EWMA update was
     var += (resid^2 >> 5) - (var >> 5)   (unsigned)
   which UNDERFLOWED u64 whenever the variance was decaying (new squared
   residual below the running variance), corrupting the statistic. Fixed
   as a signed delta:
     int64_t r2 = resid*resid;
     int64_t delta = (r2 >> 5) - (int64_t)(var >> 5);
     var = (uint64_t)((int64_t)var + delta);
   delta is bounded below by -(var >> 5), so the sum cannot go negative.
   Precision note: a FUSED unsigned `var += (r2>>5) - (var>>5)` is
   modular and self-correcting whenever the true result is non-negative,
   so the observed corruption implies the earlier form computed the delta
   in a separate step or narrower width; the signed form is
   unconditionally safe regardless of grouping. The population u32 path
   uses the same shape with small magnitudes.
2. UNCONDITIONAL BYTE SNAPSHOT/RESET SEMANTICS [UNCOMMITTED ct.cpp]:
   The per-window byte snapshot (wbytes = ct_window_bytes;
   ct_window_bytes = 0) is taken for EVERY window under the fence,
   mirroring the mask snapshots; the EWMA fold runs only for valid
   windows, so an invalid window's few bytes vanish (same
   discard-invalid convention as obs/rej/channels). Do not move the
   snapshot inside the valid branch.
3. PROMOTION DIAGNOSTIC USE-AFTER-REMOVE CORRECTION [UNCOMMITTED ct.cpp]:
   ct_persist_observe captured the promo env id BEFORE ct_pend_remove()
   (which swap-with-last-overwrites the removed entry) so the
   [CT-PERSIST] promo print reports the true first_env_id. Order matters:
   promo_first_env = p.first_env_id; ct_pend_remove(pi); then print.
4. Probe-slot semantics: processProbeRequestShared's return value is a
   transient handle; identities are re-read from probeList under the
   commit fence and immediately copied — the slot index is never stored
   persistently (see §7).
5. Validity redefinition (Step 5 revision of the 4.2 rule): valid =
   unpaused (NOT obs > 0); zero-observation windows are real readings;
   ct_obs_count is a diagnostic descriptor only and cannot distinguish
   "empty RF" from "nothing qualifying on air".
6. window_count counts VALID windows only (deliberate semantics
   revision); n_pre derives from acc.window_count - 1 (the former
   ct_n_obs counter was removed).
7. CT mode re-entry clears ALL Core-0/Core-1 scratch without the fence
   (safe because the feeder call site is RADIO_CT-gated) so stale
   pre-exit state cannot leak into the first post-re-entry window.
8. Diagnostics are snapshot-driven (taken before the possible commit) so
   a same-window commit cannot print post-reset values.
